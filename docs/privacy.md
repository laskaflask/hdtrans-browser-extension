# 개인정보처리방침 (Privacy Policy)

hdTrans 일본어 번역 브라우저 확장 프로그램 · 시행일 2026년 10월 23일

## 한국어

이 확장 프로그램은 개인정보를 수집하지 않습니다.

- **번역**: 사용자가 번역을 요청한 탭의 글자를 읽어, 확장 프로그램에 포함된 번역 엔진(hdTrans)으로 브라우저 안에서
  번역합니다. 페이지 내용, 주소, 방문 기록은 어떤 서버로도 보내지 않으며 개발자도 받지 않습니다.
- **저장하는 정보**: 사용자가 정한 설정과 직접 만든 사용자 사전만 이 브라우저의 확장 프로그램 저장소(`storage.local`)에
  저장합니다. 이 정보는 기기 밖으로 나가지 않으며, 확장 프로그램을 지우면 함께 지워집니다.
- **네트워크**: 확장 프로그램은 자신의 패키지에 든 파일(번역 엔진과 사전)만 읽으며, 외부 서버에 접속하지 않습니다.
- **분석·광고**: 사용 통계, 오류 보고, 광고, 추적 도구를 쓰지 않습니다.
- **제3자 제공**: 수집하는 정보가 없으므로 판매하거나 제3자에게 제공하는 정보도 없습니다.
- **권한**: 모든 사이트 접근 권한을 요구하지 않습니다. 우클릭 메뉴, 툴바(주소창) 아이콘, 단축키로 번역을 요청한 탭에만
  일시적으로 접근합니다.

이 방침이 바뀌면 이 문서와 저장소의 변경 기록에 남깁니다. 문의는
[GitHub 이슈](https://github.com/laskaflask/hdtrans-browser-extension/issues)로 받습니다.

## English

This extension does not collect personal data.

- **Translation**: When you ask it to translate a tab, it reads that page's text and translates it inside your
  browser with the bundled hdTrans engine. Page content, addresses and browsing history are never sent to any server,
  and the developer never receives them.
- **Stored data**: Only your settings and the user dictionaries you create are stored, in the extension's local
  storage (`storage.local`) in this browser. They never leave your device and are removed with the extension.
- **Network**: The extension only reads files packaged with it (the engine and dictionary). It does not connect to
  any server.
- **Analytics and ads**: No usage statistics, crash reporting, advertising or tracking.
- **Third parties**: As nothing is collected, nothing is sold or shared.
- **Permissions**: No access to all websites is requested. The extension gets temporary access only to the tab you
  ask to translate (context menu, toolbar or address bar icon, keyboard shortcut).

Changes to this policy are recorded in this document and the repository history. Questions:
[GitHub issues](https://github.com/laskaflask/hdtrans-browser-extension/issues).
